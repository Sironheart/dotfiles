# Pi workflow

- An approved goal permits project-file edits, local checks, and dependency/tool downloads and installs under the shared dependency policy. Commits, pushes, applies, deployments, and service mutations still require explicit approval.
- Plan when scope or risk warrants it. Clarify an unapproved goal before editing; small approved fixes need no separate planning ceremony.
- Use the read-only `general-purpose` subagent for research and review only. It returns findings; the parent saves notes or makes approved edits, including when a skill asks a worker to write a report.
